Voici les solutions détaillées pour mettre chaque nombre complexe sous forme exponentielle reiθr e^{i\theta} (avec r>0r > 0).

Première ligne

1. (ei3π4)3(e^{i\frac{3\pi}{4}})^3

  • Règle : (eiθ)n=einθ(e^{i\theta})^n = e^{in\theta}

  • Calcul :

(ei3π4)3=ei⋅3⋅3π4=ei9π4(e^{i\frac{3\pi}{4}})^3 = e^{i \cdot 3 \cdot \frac{3\pi}{4}} = e^{i\frac{9\pi}{4}}

  • Forme canonique (modulo 2π2\pi) : 9π4=2π+π4\frac{9\pi}{4} = 2\pi + \frac{\pi}{4}

ei9π4=eiπ4e^{i\frac{9\pi}{4}} = e^{i\frac{\pi}{4}}

2. (2e−iπ6)−3(2e^{-i\frac{\pi}{6}})^{-3}

  • Règle : (a⋅b)n=an⋅bn(a \cdot b)^n = a^n \cdot b^n

  • Calcul :

(2e−iπ6)−3=2−3⋅e−iπ6⋅(−3)=18ei3π6=18eiπ2(2e^{-i\frac{\pi}{6}})^{-3} = 2^{-3} \cdot e^{-i\frac{\pi}{6} \cdot (-3)} = \frac{1}{8} e^{i\frac{3\pi}{6}} = \frac{1}{8} e^{i\frac{\pi}{2}}

3. eiπ3(eiπ8)2\frac{e^{i\frac{\pi}{3}}}{(e^{i\frac{\pi}{8}})^2}

  • Calcul du dénominateur : (eiπ8)2=ei2π8=eiπ4(e^{i\frac{\pi}{8}})^2 = e^{i\frac{2\pi}{8}} = e^{i\frac{\pi}{4}}

  • Règle de division : eiaeib=ei(a−b)\frac{e^{ia}}{e^{ib}} = e^{i(a-b)}

  • Calcul :

eiπ3eiπ4=ei(π3−π4)=ei4π−3π12=eiπ12\frac{e^{i\frac{\pi}{3}}}{e^{i\frac{\pi}{4}}} = e^{i(\frac{\pi}{3} - \frac{\pi}{4})} = e^{i\frac{4\pi - 3\pi}{12}} = e^{i\frac{\pi}{12}}

4. (eiπ3)3(eiπ2)3(e^{i\frac{\pi}{3}})^3 (e^{i\frac{\pi}{2}})^3

  • Calcul des puissances :

  • (eiπ3)3=eiπ(e^{i\frac{\pi}{3}})^3 = e^{i\pi}

  • (eiπ2)3=ei3π2(e^{i\frac{\pi}{2}})^3 = e^{i\frac{3\pi}{2}}

  • Produit :

eiπ⋅ei3π2=ei(π+3π2)=ei5π2=eiπ2e^{i\pi} \cdot e^{i\frac{3\pi}{2}} = e^{i(\pi + \frac{3\pi}{2})} = e^{i\frac{5\pi}{2}} = e^{i\frac{\pi}{2}}

5. (e−iπ4)6(eiπ2)6(e^{-i\frac{\pi}{4}})^6 (e^{i\frac{\pi}{2}})^6

  • Méthode directe (regroupement des termes) :

(e−iπ4⋅eiπ2)6=(ei(−π4+π2))6=(eiπ4)6=ei6π4=ei3π2\left( e^{-i\frac{\pi}{4}} \cdot e^{i\frac{\pi}{2}} \right)^6 = \left( e^{i(-\frac{\pi}{4} + \frac{\pi}{2})} \right)^6 = \left( e^{i\frac{\pi}{4}} \right)^6 = e^{i\frac{6\pi}{4}} = e^{i\frac{3\pi}{2}}

6. (3eiπ3¯)2(\overline{3e^{i\frac{\pi}{3}}})^2

  • Règle du conjugué : reiθ¯=re−iθ\overline{r e^{i\theta}} = r e^{-i\theta}
  • Calcul :
  • Conjugué : 3eiπ3¯=3e−iπ3\overline{3e^{i\frac{\pi}{3}}} = 3e^{-i\frac{\pi}{3}}
  • Élévation au carré : (3e−iπ3)2=32e−i2π3=9e−i2π3(3e^{-i\frac{\pi}{3}})^2 = 3^2 e^{-i\frac{2\pi}{3}} = 9 e^{-i\frac{2\pi}{3}} (ou 9ei4π39 e^{i\frac{4\pi}{3}})

Seconde ligne

7. (2ei3π4)−2¯\overline{(2e^{i\frac{3\pi}{4}})^{-2}}

  • Calcul de l’intérieur :

(2ei3π4)−2=2−2e−i6π4=14e−i3π2=14eiπ2(2e^{i\frac{3\pi}{4}})^{-2} = 2^{-2} e^{-i\frac{6\pi}{4}} = \frac{1}{4} e^{-i\frac{3\pi}{2}} = \frac{1}{4} e^{i\frac{\pi}{2}}

  • Conjugué :

14eiπ2¯=14e−iπ2\overline{\frac{1}{4} e^{i\frac{\pi}{2}}} = \frac{1}{4} e^{-i\frac{\pi}{2}}

8. (eiπ32eiπ6)−2\left(\frac{e^{i\frac{\pi}{3}}}{2e^{i\frac{\pi}{6}}}\right)^{-2}

  • Simplification du quotient intérieur :

eiπ32eiπ6=12ei(π3−π6)=12eiπ6\frac{e^{i\frac{\pi}{3}}}{2e^{i\frac{\pi}{6}}} = \frac{1}{2} e^{i(\frac{\pi}{3} - \frac{\pi}{6})} = \frac{1}{2} e^{i\frac{\pi}{6}}

  • Puissance −2-2 :

(12eiπ6)−2=(1/2)−2⋅e−i2π6=22e−iπ3=4e−iπ3\left(\frac{1}{2} e^{i\frac{\pi}{6}}\right)^{-2} = (1/2)^{-2} \cdot e^{-i\frac{2\pi}{6}} = 2^2 e^{-i\frac{\pi}{3}} = 4 e^{-i\frac{\pi}{3}}

9. (eiπ3)5(ei2π3)7(e−iπ3)4\frac{(e^{i\frac{\pi}{3}})^5}{(e^{i\frac{2\pi}{3}})^7 (e^{-i\frac{\pi}{3}})^4}

  • Numerateur : ei5π3e^{i\frac{5\pi}{3}}

  • Dénominateur : ei14π3⋅e−i4π3=ei10π3e^{i\frac{14\pi}{3}} \cdot e^{-i\frac{4\pi}{3}} = e^{i\frac{10\pi}{3}}

  • Quotient :

ei5π3ei10π3=ei(5π3−10π3)=e−i5π3=eiπ3\frac{e^{i\frac{5\pi}{3}}}{e^{i\frac{10\pi}{3}}} = e^{i(\frac{5\pi}{3} - \frac{10\pi}{3})} = e^{-i\frac{5\pi}{3}} = e^{i\frac{\pi}{3}}

10. (2eiπ3)−3(2eiπ6)4(2e^{i\frac{\pi}{3}})^{-3} (\sqrt{2}e^{i\frac{\pi}{6}})^4

  • Premier terme : (2eiπ3)−3=2−3e−iπ=18e−iπ(2e^{i\frac{\pi}{3}})^{-3} = 2^{-3} e^{-i\pi} = \frac{1}{8} e^{-i\pi}

  • Second terme : (2eiπ6)4=(2)4ei4π6=4ei2π3(\sqrt{2}e^{i\frac{\pi}{6}})^4 = (\sqrt{2})^4 e^{i\frac{4\pi}{6}} = 4 e^{i\frac{2\pi}{3}}

  • Produit :

18⋅4⋅ei(−π+2π3)=12e−iπ3\frac{1}{8} \cdot 4 \cdot e^{i(-\pi + \frac{2\pi}{3})} = \frac{1}{2} e^{-i\frac{\pi}{3}}

11. (ieiπ3)6(−ei2π3)−2\frac{(i e^{i\frac{\pi}{3}})^6}{(-e^{i\frac{2\pi}{3}})^{-2}}

  • Numerateur :

  • Comme i=eiπ2i = e^{i\frac{\pi}{2}}, on a ieiπ3=ei(π2+π3)=ei5π6i e^{i\frac{\pi}{3}} = e^{i(\frac{\pi}{2} + \frac{\pi}{3})} = e^{i\frac{5\pi}{6}}

  • (ei5π6)6=ei5π=eiπ=−1(e^{i\frac{5\pi}{6}})^6 = e^{i5\pi} = e^{i\pi} = -1

  • Dénominateur :

  • (−ei2π3)−2=(−1)−2⋅(ei2π3)−2=1⋅e−i4π3(-e^{i\frac{2\pi}{3}})^{-2} = (-1)^{-2} \cdot (e^{i\frac{2\pi}{3}})^{-2} = 1 \cdot e^{-i\frac{4\pi}{3}}

  • Quotient :

ei5πe−i4π3=ei(5π+4π3)=ei19π3=ei(6π+π3)=eiπ3\frac{e^{i5\pi}}{e^{-i\frac{4\pi}{3}}} = e^{i(5\pi + \frac{4\pi}{3})} = e^{i\frac{19\pi}{3}} = e^{i(6\pi + \frac{\pi}{3})} = e^{i\frac{\pi}{3}}
