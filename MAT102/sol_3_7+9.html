Exercice 7. Orthogonalité des vecteurs

Deux vecteurs u⃗\vec{u} et v⃗\vec{v} sont orthogonaux si et seulement si leur produit scalaire est nul : u⃗⋅v⃗=0\vec{u} \cdot \vec{v} = 0.

a) u⃗=(t−1,2t−3)\vec{u} = (t - 1, 2t - 3), v⃗=(3,−1)\vec{v} = (3, -1)

u⃗⋅v⃗=3(t−1)−1(2t−3)=3t−3−2t+3=t\vec{u} \cdot \vec{v} = 3(t - 1) - 1(2t - 3) = 3t - 3 - 2t + 3 = t

u⃗⋅v⃗=0⇔t=0\vec{u} \cdot \vec{v} = 0 \iff t = 0

b) u⃗=(3t,2+t,−t)\vec{u} = (3t, 2 + t, -t), v⃗=(1,1,2)\vec{v} = (1, 1, 2)

u⃗⋅v⃗=1(3t)+1(2+t)+2(−t)=3t+2+t−2t=2t+2\vec{u} \cdot \vec{v} = 1(3t) + 1(2 + t) + 2(-t) = 3t + 2 + t - 2t = 2t + 2

u⃗⋅v⃗=0⇔2t+2=0⇔t=−1\vec{u} \cdot \vec{v} = 0 \iff 2t + 2 = 0 \iff t = -1

c) u⃗=(t−1,2t,2)\vec{u} = (t - 1, 2t, 2), v⃗=(1,2,−1)\vec{v} = (1, 2, -1)

u⃗⋅v⃗=1(t−1)+2(2t)−1(2)=t−1+4t−2=5t−3\vec{u} \cdot \vec{v} = 1(t - 1) + 2(2t) - 1(2) = t - 1 + 4t - 2 = 5t - 3

u⃗⋅v⃗=0⇔5t−3=0⇔t=35\vec{u} \cdot \vec{v} = 0 \iff 5t - 3 = 0 \iff t = \frac{3}{5}

d) u⃗=(t2+1,2t,t2−1)\vec{u} = (t^2 + 1, 2t, t^2 - 1), v⃗=(t2,−t,1)\vec{v} = (t^2, -t, 1)

u⃗⋅v⃗=t2(t2+1)−t(2t)+1(t2−1)=t4+t2−2t2+t2−1=t4−1\vec{u} \cdot \vec{v} = t^2(t^2 + 1) - t(2t) + 1(t^2 - 1) = t^4 + t^2 - 2t^2 + t^2 - 1 = t^4 - 1

u⃗⋅v⃗=0⇔t4−1=0⇔(t2−1)(t2+1)=0\vec{u} \cdot \vec{v} = 0 \iff t^4 - 1 = 0 \iff (t^2 - 1)(t^2 + 1) = 0

Comme t2+1>0t^2 + 1 > 0 pour tout t∈ℝt \in \mathbb{R}, l’équation équivaut à t2−1=0t^2 - 1 = 0, soit :

t=1out=−1t = 1 \quad \text{ou} \quad t = -1

Exercice 9. Colinéarité des vecteurs

Deux vecteurs (x,y)(x, y) et (x′,y′)(x', y') dans ℝ2\mathbb{R}^2 sont colinéaires si et seulement si leur déterminant est nul : xy′−x′y=0xy' - x'y = 0.

a) u⃗=(1−t,2+t)\vec{u} = (1 - t, 2 + t), v⃗=(3,4)\vec{v} = (3, 4)

det(u⃗,v⃗)=4(1−t)−3(2+t)=4−4t−6−3t=−7t−2\det(\vec{u}, \vec{v}) = 4(1 - t) - 3(2 + t) = 4 - 4t - 6 - 3t = -7t - 2

det(u⃗,v⃗)=0⇔−7t−2=0⇔t=−27\det(\vec{u}, \vec{v}) = 0 \iff -7t - 2 = 0 \iff t = -\frac{2}{7}

b) u⃗=(5t,6)\vec{u} = (5t, 6), v⃗=(6t,7)\vec{v} = (6t, 7)

det(u⃗,v⃗)=7(5t)−6(6t)=35t−36t=−t\det(\vec{u}, \vec{v}) = 7(5t) - 6(6t) = 35t - 36t = -t

det(u⃗,v⃗)=0⇔t=0\det(\vec{u}, \vec{v}) = 0 \iff t = 0

c) u⃗=(2,1)\vec{u} = (2, 1), v⃗=(3−t,2−t)\vec{v} = (3 - t, 2 - t)

det(u⃗,v⃗)=2(2−t)−1(3−t)=4−2t−3+t=1−t\det(\vec{u}, \vec{v}) = 2(2 - t) - 1(3 - t) = 4 - 2t - 3 + t = 1 - t

det(u⃗,v⃗)=0⇔1−t=0⇔t=1\det(\vec{u}, \vec{v}) = 0 \iff 1 - t = 0 \iff t = 1
